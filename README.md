# JustPlay Helper (Android source)

Aplicação Android simples com temporizador ajustável e controlos Iniciar/Parar.
Não automatiza nem clica em anúncios da JustPlay e não tenta fabricar visualizações/recompensas.

## Como compilar
1. Instala o Android Studio num computador.
2. Abre a pasta `JustPlayHelper` no Android Studio.
3. Aguarda a sincronização do Gradle.
4. Seleciona **Build > Build APK(s)**.
5. O APK de depuração será normalmente criado em `app/build/outputs/apk/debug/app-debug.apk`.

Requer Android SDK 35 instalado no Android Studio. O projeto usa Gradle com plugin Android 8.7.3.
